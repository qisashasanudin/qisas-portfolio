# Qisas Hasanudin Portfolio

A responsive personal portfolio built with React, TypeScript, Vite, and Material UI.

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages Deployment

This repository includes a GitHub Actions workflow at `.github/workflows/deploy.yml`.

1. Push the project to a GitHub repository.
2. In GitHub, open `Settings > Pages`.
3. Set `Source` to `GitHub Actions`.
4. Push to `main`; the workflow will build and deploy the site.

The Vite `base` path is calculated automatically for both `qisashasanudin.github.io` and normal project repositories.
